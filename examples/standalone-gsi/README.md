# DynamoDB Table with standalone GSI example

Configuration in this directory creates an AWS DynamoDB table whose global secondary indexes are managed as standalone `aws_dynamodb_global_secondary_index` resources, so each index has an independent lifecycle instead of forcing every inline GSI to be recreated when one changes.

## Usage

To run this example you need to execute:

```bash
$ terraform init
$ terraform plan
$ terraform apply
```

Note that this example may create resources which can cost money (AWS Elastic IP, for example). Run `terraform destroy` when you don't need these resources.
